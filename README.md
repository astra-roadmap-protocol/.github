## Documentation Overview

### System Documentation (`docs/markdown/System/`)

Core project documentation including:
- **ASTRA_MASTER_BLUEPRINT.md** - Complete technical architecture and roadmap
- **ASTRA_EXECUTIVE_SUMMARY.md** - Business overview and value proposition
- **ASTRA_SUMMARY_TABLE.md** - Quick reference tables
- **ASTRA_DELIVERABLES.md** - Project deliverables and milestones
- **ASTRA_EIGENCLOUD_ENTERPRISE.md** - Enterprise solutions documentation
- **ASTRA-PROPOSAL.md** - Project proposal and specifications

### Reference Documentation (`docs/markdown/referrence/`)

Design, UX, and planning documents:
- **FILES-NAVIGATION-MAP.md** - Complete file navigation guide
- **CodePath-Platform-Roadmap.md** - Platform development roadmap
- **CodePath-GTM-Execution.md** - Go-to-market execution plan
- **Astra-Brand-UX-System.md** - Brand and UX guidelines
- **ASTRA-VISUAL-DESIGN-SYSTEM.md** - Visual design specifications
- **ASTRA-USER-FLOWS-DETAILED.md** - Detailed user flow documentation
- **astra-logo-complete.md** - Logo system documentation

### Integration & Research (`docs/markdown/`)

Technical integration guides and research:
- SDK integration documentation
- Official package references
- Fork and clone blueprints
- Quick start scripts
- Repository summaries

## Brand Assets

The `logo/` directory contains the complete ASTRA brand identity system:
- Primary logo variations (Main, Monochrome, Gradients, Iridescent)
- Multiple format options (Mark only, Wordmark, Stacked)
- Color variations (Primary, Dark Teal, Light Teal)
- Usage guidelines and specifications
